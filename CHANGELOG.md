# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Collapsible signature panel: an edge button folds the panel away, and it starts collapsed when
  the viewer is narrower than `signaturePanelBreakpoint` (default 760 px). New labels
  `showSignaturePanel` and `hideSignaturePanel`.
- Signature fields: `signatureFields`, `fieldsMode` (`fill` or `edit`), `freePlacement` and
  `fieldsChange` on the viewer; `SigningSession` `fields`, `setFields`, `fillField`, `clearField`,
  `validate()`, `missingRequiredFields`; `exportPdf({ requireAllFields })`; `fieldId` in exported
  coordinates; `SignoraFieldEditorComponent`; field tokens in the theme.
- Guide for AI agents (`AGENTS.md`, shipped in the package, plus `llms.txt` / `llms-full.txt`),
  generated and checked by `npm run docs:ai` / `docs:ai:check`; `context7.json` for Context7.
- Viewer `viewMode` (`paged` or `continuous`), `signatureModes` (draw, type, upload, other),
  `preloadedSignatures` (assets, typed names and images) and a `placementsChange` output.
- `session.addAssets()` and `session.exportCoordinates()` (normalized and PDF-point boxes, for
  backends that stamp the PDF themselves); `<signora-signature-panel [providerTabs]>`.
- Viewer `readOnly` (show signatures without editing) and `coordinatesChange` (+
  `coordinatesIncludeImages`) output with the exported coordinates.
- Playground controls for the new options; see `docs/viewer-options.md`.
- Live theme editor in the playground (presets, color pickers, radius, font) that outputs the CSS.
- API reference generated with TypeDoc (`npm run docs:api`); every public symbol is documented.
- README screenshots, regenerated by `npm run screenshots`.
- Component integration tests for the viewer, toolbar, signature layer and panel, the upload
  validation and the theme directive.
- `--signora-signature-bg` and `--signora-radius-lg` tokens.

### Fixed

- Keyboard users could not scroll the page: the scrollable area is now the single focus stop.
- The signature panel no longer emits a fixed heading level.
- Signature thumbnails, the drawing pad and the typed preview always sit on paper, so dark ink
  stays visible in dark themes.
- A pill-shaped `--signora-radius` (for example `999px`) no longer distorts large surfaces.
- Key repeat on a placement used stale state when several keys arrived before a re-render.

- Digital signing workflow: `SigningWorkflow` exports the visual signatures, then delegates the
  cryptographic signature to a `DigitalSignatureProvider`. It rejects results that are not PDFs and
  providers that claim a cryptographic signature but return none.
- `signora-pdf/http`: `HttpDigitalSignatureProvider` and `HttpCertificateProvider`
  (`withHttpDigitalSigner()`, `withHttpCertificateProvider()`) built on `HttpClient`.
- `hasDigitalSignature()`, `looksLikePdf()` and `DigitalSigningError` in the core.
- Playground _Digital signing_ page with a clearly labelled **simulated** provider and the HTTP
  provider.
- `docs/digital-signing.md`.

- Visual export: `PdfLibDocumentWriter` draws placed signatures with pdf-lib, honouring CropBox and
  `/Rotate`, and `SigningSession.exportPdf()` returns the new PDF (the loaded one is untouched).
  Refuses to modify an already digitally signed PDF unless
  `allowInvalidatingExistingSignatures` is set.
- Playground: preview (modal, independent viewer) and download of the exported PDF.

- Signature creation in `signora-pdf/ui`: draw pad (mouse, touch, stylus with pressure),
  typed signatures with configurable fonts (`SIGNORA_SIGNATURE_FONTS`), image upload (normalized
  to PNG) and `<signora-signature-panel>` with ARIA tabs.
- `withOrganizationSignatures()` to register predefined signatures, logos and stamps.
- Placement: `<signora-signature-layer>` places the armed signature on click or drop, moves it,
  resizes it from the corners keeping proportions, nudges it with the keyboard and deletes it.
  Works with several signatures across pages, zoom and viewer rotation.
- Pure placement geometry in the core (`createPlacementRect`, `moveRect`,
  `resizeRectFromCorner`, `scaleRect`) and signature library / selection state in `SigningSession`.
- `showSignaturePanel` input and `signatures` slot on `<signora-viewer>`.

### Changed

- `SignoraLabels` gained the strings of the signature UI.
- Loading a document resets viewer rotation, placements and the armed signature (the signature
  library is kept).

## [0.1.0-alpha.0] - 2026-11-22

### Added

- Angular workspace with the publishable library `signora-pdf` and a playground app.
- Core entry point: domain models, ports (rendering, writer, signature provider, digital
  signature and certificate providers), DI tokens and `provideSignora()` features.
- Normalized coordinate model with conversions to viewport pixels and PDF user space, handling
  zoom, viewer rotation, intrinsic `/Rotate` and CropBox offsets.
- Headless, signal-based `SigningSession` (document, page, zoom, rotation, placements).
- `signora-pdf/pdfjs`: PDF.js rendering adapter (URL, Blob, ArrayBuffer, Uint8Array).
- `signora-pdf/pdf-lib`: writer wiring (embedding signatures is not implemented yet).
- `signora-pdf/ui`: viewer, page and toolbar components, template slots, theme directive and
  translatable labels, themed through `--signora-*` CSS variables.
- Playground with upload, drag and drop, sample documents, live theme presets and a custom
  template demo.
- Open-source repository files and GitHub Actions workflows.
