## Instalación

```bash
npm install signora-pdf pdfjs-dist
```

Publicado en npm como [`signora-pdf`](https://www.npmjs.com/package/signora-pdf). Después sigue la [guía de instalación](getting-started/installation/) y el [inicio rápido](getting-started/quick-start/).
