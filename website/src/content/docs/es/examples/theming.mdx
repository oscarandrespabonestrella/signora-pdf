## Tema con variables CSS

La directiva `signoraTheme` establece variables `--signora-*` desde un objeto. Los mismos tokens
funcionan en CSS normal. El pad de dibujo se queda sobre «papel» blanco incluso en un tema oscuro
para que la tinta se vea. Todos los tokens están en [temas](../../guides/theming/).

## Barra personalizada

Sustituye cualquier sección con `<ng-template signoraSlot="...">`. La plantilla recibe la
`SigningSession`, así que una barra son solo botones que llaman a sus métodos.
