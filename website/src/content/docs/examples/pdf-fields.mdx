## Create signature fields in the PDF

Lay the fields out on the page, then create them in the file as real AcroForm signature fields.
They are empty: a backend signs into them by name. The result is read back with
`readSignatureFields()`. See [signature fields in the PDF](../../guides/signature-fields/).
