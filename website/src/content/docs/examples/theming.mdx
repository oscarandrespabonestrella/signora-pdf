## Theme with CSS variables

The `signoraTheme` directive sets `--signora-*` variables from an object. The same tokens work in
plain CSS. The drawing pad stays on white "paper" even in a dark theme so ink is visible. All
tokens are listed in [theming](../../guides/theming/).

## Custom toolbar

Replace any section with `<ng-template signoraSlot="...">`. The template receives the
`SigningSession`, so a toolbar is just buttons that call its methods.
